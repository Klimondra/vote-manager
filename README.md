# Vote manager
Vote manager je aplikace pro vytváření a správu online voleb. Projekt vznikl jako praktická ukázka práce s frameworkem Laravel a slouží jako nástroj pro organizaci komunitních hlasování na Minecraft serveru Respublica.

## Funkce
- Vytváření online voleb v administrátorském panelu
- Přihlašování čistě přes Discord OAuth2
- Možnost hlasování pouze jednou
- Zobrazení výsledků voleb po skončení hlasování
- Přístup do panelu na základě oprávnění uživatele
